# Event Ticket Booking System

A full-stack web application for discovering and booking events. The application allows users to register, log in, browse available events, book tickets, and view their bookings.

## Features

- User registration and login
- JWT-based authentication
- Browse all available events
- View event details
- Book tickets
- Calculate total ticket price
- View booking history
- User logout
- Event management
- Responsive user interface

## Technologies Used

### Frontend

- React.js
- React Router
- Axios
- Bootstrap
- Vite

### Backend

- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- JWT Authentication
- Maven

### Database

- MySQL
